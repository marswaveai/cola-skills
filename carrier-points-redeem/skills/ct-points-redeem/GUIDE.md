# 电信积分兑话费

Cola 中入口默认把电信话费交给本人手机办理（Cola 浏览器无法模拟手机 UA）；本文件只在用户要在电脑上查询、或宿主已提供设备模拟时读取。共同授权、浏览器和证据规则沿用统一入口。只办本机、现金 0、一次到账的话费直充；不办分期返还、业务抵用金、流量、会员、金豆或短信直兑。

## 登录直达

新任务默认未登录，第一步直接打开下面的完整官方登录地址；不先访问话费专区，不检查 UA、日期或旧会话。桌面环境也能打开登录表单。

看到“欢迎登录 / 天翼积分商城”、手机号码和短信验证码输入框即交接本人。保留完整回跳参数；`appCode=CALLS` 与 `channelCode=HGOKHD` 是不同字段，不自行缩短或替换。本人确认后才核对账户和办理业务。

## 登录后再检查兑换条件

- 查询可直接读取账户和当前可兑信息。需要兑换时，才按 [移动环境](../../references/browser.md#电信移动环境) 设置真实移动 UA 和移动视口，再同页加载话费专区；**必须在点“兑换”建单前完成，不能因此拦截登录。**
- 目标缺少 UA/设备模拟时停在下单前，交由本人手机办理后续兑换；不以 resize 或修改 navigator 代替请求 UA，不私连 CDP 或擅改全局配置。
- 时间窗在登录后按当前页面核对，历史规则为当月 5–31 日；不以日期限制阻止打开登录页。

## 最短流程

1. **登录后业务页**：官网应回到 <https://apps.telefen.com/jycalls/?channelCode=HGOKHD>；未回跳时本人确认登录完成后在同页打开该地址。不要额外登录星级中心或 PC 账号体系。
2. **查询**：核对脱敏账户和充值号码，等可用积分、面额、成本及规则加载完成。合法 0 可如实报告，空白不当 0。查询任务只读，到此停止。
3. **选面额**：用户已指定就直接核对，否则列当前可用面额供选择。不套用旧样本价格。默认一次直充；规则不清才读 [话费规则](references/phonefee.md)。核对本机、积分足够、无现金、当前时间窗及不可退条件。
4. **沿用授权**：已明确要兑所选面额时，一次告知实际积分、现金 0 及不可退，不再重复确认。积分不足、现金项、指定面额不存在、超用户预算或成本异常时停下说明；不硬编码全国兑换比例。
5. **建单一次**：在回复中记下本笔阶段，点“兑换”一次，读取返回的订单号和收银台。预期为 `cashier.telefen.com/dopay`；页面慢或工具超时先查原笔，不重建。
6. **收银台**：核对订单号、收款方、本单积分、可用积分、面额及现金条件。无现金行须同时有明确纯积分规则，才能判断现金 0；有现金行但金额空白不能判 0。符合授权才点一次“确认支付”进入验证。
7. **本人验证**：在原记录保存阶段和订单号，交接同页，让本人获取短信、填码并按页面确认。Agent 不读验证码、不自动重发；本人回来后先核对结果，不再支付。
8. **同会话取证**：优先读取成功页 `apps.telefen.com/jycalls/Success`、收银台和对应订单。分别记录提交、实际扣分、现金、平台状态、到账证据。查 `jf.189.cn` 的积分/订单可能需要额外 PC 登录，仅在确需独立核验时说明并由用户决定。

默认由本人完成登录与支付验证各一次短信，实际验证要求以官网为准。

## 异常与恢复

- 跳回 `jf.189.cn/pchome`：按 UA/会话异常处理，停止点击，先查既有订单；修复移动环境后只继续原笔，不重新点兑换。
- 待支付、处理中、无响应或结果不明：只读查订单及积分。旧收银台链接过期不代表未建单，不复用历史 `payflag`，也不以新建订单当修复。
- 已有重复待支付订单：先核对各笔并确定要继续的一笔，未扣分且确定重复的其余订单可按本人授权关闭，不误关正在处理的订单。
- 复杂恢复才读 [页面线索](references/browser-flow.md)；需要跨进程本地保护才读 [状态脚本](references/transaction-state.md)。查询不落盘，建单及验证使用同一条简记录，不拆多份 JSON。
- 扣分或平台“已完成”不代表到账。独立核验匹配本笔充值记录；用户说已到账则注明用户确认。按统一入口汇报。
