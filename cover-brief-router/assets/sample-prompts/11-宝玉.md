# Text Elements
唯一可见中文主标题：把周末还给自己。
画成两行「把周末」「还给自己」，不画引号或句号；不增加其他文字、英文、编号、品牌、副标题、水印或小字说明。字形准确完整，不重复标题。

# Mood Application
温暖、明亮、平衡的插画编辑封面，不忧郁、不喧闹。有一个立刻能看懂的超现实阅读隐喻，不用清单解释。

# Font Application
使用深棕色、清楚可读的宽笔中文手写标题，有自然笔触与轻微不规则，字号大，文字占据上方约28%的空间。不是电脑UI字体，也不是儿童涂鸦字。两行文字完整，距边至少7%，不能遮挡主体。

# Composition
在奶油白纸张背景上，画一册巨大展开的书，它的书页向外舒展并化成一座温暖橙黄色的小岛：翻卷书页变成层叠的小丘和一条弯曲小路，岛上只有一把安静的休憩木椅和一棵小树。它们组成一个集中的书页小岛场景，不是彼此分离的图标。书没有任何可读内容。无人脸、无真实人物。
主视觉位于中下部，占约50%的画面，形体完整，有柔和的超现实空间纵深；上方大标题、下方大插画形成完整封面而非金句分享卡。背景保留约40%的呼吸空间，但下半部必须有书页小岛的视觉支撑，不能漏排。

# Color and Rendering
按warm调色板：奶油白背景，暖橙、金黄与陶土色构成主体，深棕用于标题和少量细节。不要显示颜色名称、色值或调色板标签。
painterly表现为柔软的水彩/绘画笔触、透明色层、自然色边与纸张纹理；不使用硬黑轮廓、平整矢量色块、3D、摄影写实、赛璐璐或像素。笔触和色层可见，但不要把整张图染成旧黄纸或泥灰色。树也用温暖橙金色，不增加一大片绿色。

# Final Constraints
只生成一张3:4中文封面。只写「把周末还给自己」，无其他文字、logo、水印、日期或虚假出处。不要卡片框、步骤、圆角模块、清单、三条要点、素材板、作品拼盘或PPT。完整准确标题是第一视觉，书页化成自己的小岛是第二视觉。体现宝玉封面的metaphor × warm × painterly × title-only × balanced组合。
