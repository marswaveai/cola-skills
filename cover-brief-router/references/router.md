# 封面执行选型

用户先选视觉效果；确认文字和素材后再匹配技能。技能与风格不一一对应，一个技能可实现多个风格。每个准备提供选择的技能至少要有一张可见案例；安装了技能不等于其封面案例已验收。

| 已确认的视觉需求 | 候选技能 | 需核对的能力 |
|---|---|---|
| 真人主视觉、大标题，人物与字的构图是重点 | gbro-cover-design | 10 种构图；固定 3:4，输出提示词而非图片；需可用图像后端与适合的人像素材 |
| 巨型透视、复古拼贴等明显不同的美术方向 | punk-cover | 使用对应风格 META.md / STYLE.md 与封面蓝图；检查风格文件实际路径、比例与图像后端 |
| 摄影杂志主视觉、文字密集或既定排版 | guizang-social-card-skill | 读取原生HTML/CSS模板和对应封面布局；第10张是视觉规范样张，不是原生渲染实测 |
| 明确的一稿多发或多页排版延展 | article2media | 暂未提供合格独立封面案例，不进入默认首轮选择；不把onepage清单默认为封面 |
| 插画型文章封面 | baoyu-cover-image | 读取具体渲染风格与比例约束，检查可用图像后端；不要以小红书信息图卡替代封面 |
| 用户确实选择照片 + 涂鸦海报方向 | heytea-style | 读取对应带字/无字模板，核对照片主体是否适合 |
| 用户需要长期一致的 IP 角色 | ip-illustration-for-yourself | 读取角色建立流程，确认身份/形象锚点或其他允许输入；不要一概声称缺照片就完全不能用 |

## 验证边界

- 前文少量试验不是稳定成功率证据，不以 5 次试验声称“正确率七成”。
- HTML 文字可控不代表布局自动好看；生图文字偶尔正确也不代表稳定。按本次成品实际验收。
- 本机曾补过 Punk 样式资源，执行前仍应核对技能引用的相对路径能否读到，不能只见文件就称完全修好。
- 许可、实际商用用途与作者要求需单独核对，不把 AGPL 概括成任何使用都“有传染性”。
- 平台显示画幅与裁切可能因入口不同，不沿用未经确认的“视频号唯一尺寸”结论。
